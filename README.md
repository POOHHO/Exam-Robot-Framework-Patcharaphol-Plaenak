# Repository structure
  - keywords/    # Reusable keywords (Keywords)
  - resources/   # Config (Setting)
  - testdata/    # Test data (Variables)
  - test script  # Execute test suites (Test case)

# Getting started
  - Python below 3.14
  - Robot Framework and required libraries (SeleniumLibrary, AppiumLibrary)
  - A supported browser driver (Chrome)

# Running tests
Run a suit with Robot Framework : 
py -m robot <file_name>

Example : 
py -m robot .\posts_by_user.robot
